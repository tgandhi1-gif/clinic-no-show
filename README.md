# Reading the Waiting Room

> Empty chairs cost a clinic more than full ones. I taught a model to feel when a patient would quietly not show up.

The question: Which patients would quietly not show up, and could we see it coming?
The result: Targeted reminders cut missed appointments by roughly a fifth.

## Run
    pip install -r requirements.txt
    python main.py

## Stack
Python, scikit-learn, SQL.
